# ВАЖНО: Обнови Apps Script кода!

Трябва да обновиш Apps Script кода в Google Sheet-а ти!

## Стъпки:

1. Отвори Google Sheet: https://docs.google.com/spreadsheets/d/1mc2z-ssl5yMGl37AME5eawSbxPggDEKMi4Lqv_QnOUE/edit

2. Разширения → Apps Script

3. Изтрий всичко в редактора

4. Копирай **НОВИЯ** код от файла `GOOGLE_SHEETS_SCRIPT.gs` (кодът е променен!)

5. Постави го в Apps Script редактора

6. Запази (Ctrl+S)

7. **ВАЖНО:** Направи нов deployment:
   - Deploy → Manage deployments
   - Натисни ✏️ (Edit) до съществуващия deployment
   - Или Deploy → New deployment
   - Избери Web app
   - Execute as: Me
   - Who has access: **Anyone**
   - Натисни Deploy

8. Тествай формата отново
