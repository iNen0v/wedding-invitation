# Алтернативно решение: Google Forms

Тъй като Google Apps Script Web App не работи правилно, ето по-прост вариант:

## Вариант 1: Google Forms (Най-лесен)

### Стъпки:

1. **Създай Google Form:**
   - Отиди на https://forms.google.com
   - Създай нова форма
   - Добави следните въпроси:
     - "Твоето име" (Краткият отговор) - Задължително
     - "Име на гост" (Краткият отговор) - По избор
     - "Деца" (Краткият отговор) - По избор
     - "Ще присъстваш ли на нашата сватба?" (Множествен избор)
       - С радост потвърждвам
       - За съжаление ще откажа
     - "Избор на меню" (Множествен избор)
       - Месо
       - Вегетарианско
       - Детско

2. **Вземи Form URL:**
   - В Google Form → Натисни "Send" (Изпрати)
   - Избери "Link" (Линк)
   - Копирай URL-а (започва с `https://docs.google.com/forms/d/...`)

3. **Вземи Entry IDs:**
   - Отвори формата в браузър
   - Натисни F12 (Developer Tools)
   - Inspect Element на първото поле
   - Търси `name="entry.XXXXXXX"` (където XXXXXXX е число)
   - Повтори за всяко поле

4. **Добави в кода:**
   - Ще обновя кода да използва Google Forms

## Вариант 2: EmailJS (За изпращане на email-и)

Може да използваме EmailJS за изпращане на email-и с данните от формата.

## Вариант 3: Google Sheets API (По-сложно)

Може да използваме Google Sheets API с OAuth, но това е по-сложно.

---

**Препоръка:** Използвай **Вариант 1 (Google Forms)** - най-простият и най-надежден вариант.

Ако искаш, мога да обновя кода да използва Google Forms вместо Apps Script.
