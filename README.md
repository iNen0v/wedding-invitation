# 💐 Сватбена Покана

Красив и модерен уебсайт за сватбена покана, изграден с React и Vite.

## ✨ Функционалности

- 📖 **Интерактивна покана** - Прелистване като книга с 4 уникални страници
- 📝 **Въпросник за присъствие** - Събиране на информация от гости
- 🌿 **Цветова схема** - Бяло, перлено и зелено
- 📱 **Responsive дизайн** - Перфектно изглежда на всички устройства
- ⚡ **Бърза скорост** - Използване на Vite за оптимизация

## 🛠️ Технологии

- React 19
- Vite
- React Router
- CSS3 с анимации

## 🚀 Стартиране

\`\`\`bash
# Инсталиране на зависимости
npm install

# Стартиране на development сървър
npm run dev

# Build за production
npm run build

# Preview на production build
npm run preview
\`\`\`
