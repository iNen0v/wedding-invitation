# Обновяване на заглавния ред в Google Sheet

## Проблем
Google Sheet има стари колони, които не съвпадат с новите полета от формата.

## Решение

Apps Script кодът вече автоматично проверява и обновява заглавния ред. Ето какво трябва да направиш:

### Стъпка 1: Обнови Apps Script кода

1. Отвори Google Sheet: https://docs.google.com/spreadsheets/d/1mc2z-ssl5yMGl37AME5eawSbxPggDEKMi4Lqv_QnOUE/edit
2. Разширения → Apps Script
3. Копирай новия код от `GOOGLE_SHEETS_SCRIPT.gs`
4. Постави го в редактора (замени стария код)
5. Запази (Ctrl+S или Cmd+S)

### Стъпка 2: Направи нов deployment

1. Deploy → Manage deployments
2. Натисни ✏️ Edit на съществуващия deployment
3. Натисни "Deploy"
4. Копирай новия URL (ако се е променил)

### Стъпка 3: Тествай

1. Отвори формата и изпрати тестови данни
2. Apps Script автоматично ще обнови заглавния ред при първото изпращане
3. Провери Google Sheet - трябва да видиш правилните колони:
   - Име
   - Контакт
   - Присъствие
   - Има гост
   - Име на гост
   - Меню за гост
   - Има деца
   - Брой деца
   - Деца (детайли)
   - Меню
   - Специални изисквания
   - Дата/Час

### Стъпка 4: Ръчно обновяване (опционално)

Ако искаш да обновиш заглавния ред ръчно:

1. Изтри първия ред (заглавния ред)
2. Apps Script автоматично ще създаде новия при следващото изпращане

Или:

1. Ръчно попълни първия ред с:
   ```
   Име | Контакт | Присъствие | Има гост | Име на гост | Меню за гост | Има деца | Брой деца | Деца (детайли) | Меню | Специални изисквания | Дата/Час
   ```

## Важно

Apps Script кодът автоматично проверява дали заглавният ред е правилен при всяко изпълнение. Ако не е, той автоматично го обновява.
